## Screenshot Guidelines

When adding screenshots:

1. **Resolution**: Preferably 1080x1920 (standard phone portrait)
2. **Format**: PNG for UI screenshots, JPG for photos
3. **File Naming**: Use descriptive names (e.g., `01-login-screen.png`, `02-field-selection-point.png`)
4. **Privacy**: Remove any personal information (names, phone numbers, actual farmer data)
5. **Clean Data**: Use test accounts and sample fields
6. **Good Quality**: High-resolution, clear text, proper lighting

## Privacy & Security

⚠️ **Important**: Do NOT include screenshots containing:
- Real farmer names, phone numbers, or addresses
- Actual GPS coordinates of private fields
- API keys or credentials visible in UI
- Backend URLs with tokens
- Any confidential or sensitive information

Use test data or blur sensitive information before adding screenshots.
